# StepUp Admin Challenge Management

## Design Objective

Create an Admin Challenge Management page that visually matches the existing StepUp Challenge page exactly.

The layout, spacing, color palette, typography, sidebar, top navigation, cards, and overall structure must remain identical to the user-facing Challenge page.

Do NOT redesign the interface.

Only extend the existing design with administrative controls.

---

# Layout Structure

## Left Sidebar

Keep exactly the same:

* StepUp Logo
* Dashboard
* Rewards
* Leaderboard
* My Challenges
* Community Feed
* Collections
* Route History

Add one new menu item:

* Challenge Management

Use the same icon style and active state styling.

---

## Top Navigation

Keep exactly the same:

* Search Bar
* User Profile Avatar
* Dropdown Menu

No visual changes.

---

# Hero Banner Section

Keep the same large promotional banner style.

Instead of:

"Spring Step Challenge Event"

Admin sees:

"Challenge Management Center"

Subtitle:

Manage all active, upcoming, and archived challenges from a single dashboard.

Buttons:

* Create Challenge (Primary Purple Button)
* View Analytics (Secondary Button)

Maintain identical button styles from the original page.

---

# Challenge Cards Section

Reuse the exact same challenge card design.

Each card should still contain:

* Banner Image
* Challenge Name
* Progress Bar
* Remaining Days
* Participant Count

Add an Admin Action Area at the bottom.

Replace:

"Join Challenge"

with:

[ Edit ] [ Delete ]

Buttons should match StepUp styling.

---

# Create Challenge

When clicking Create Challenge:

Open a centered modal.

The modal should follow StepUp design language:

* Rounded corners
* Soft shadow
* White background
* Purple accents

Fields:

Challenge Name

Description

Banner Upload

Challenge Type

* Daily
* Weekly
* Monthly
* Team
* Event

Goal Type

* Steps
* Distance
* Active Minutes

Goal Value

Reward Points

Badge Reward

Start Date

End Date

Status

* Draft
* Active
* Archived

Buttons:

* Save Challenge
* Cancel

---

# Edit Challenge

Use the same modal design as Create Challenge.

Pre-fill all existing data.

Buttons:

* Update Challenge
* Cancel

---

# Delete Challenge

Use a small confirmation modal.

Message:

Are you sure you want to delete this challenge?

This action cannot be undone.

Buttons:

* Delete
* Cancel

---

# Challenge Analytics Section

Place below the challenge cards.

Use the same card style already used throughout StepUp.

Four statistic cards:

* Total Challenges
* Active Participants
* Completed Challenges
* Reward Points Distributed

Each card should contain:

* Icon
* Large Number
* Small Description

Maintain existing spacing and visual hierarchy.

---

# Visual Style Rules

IMPORTANT:

The generated design must look like it belongs to the same StepUp product.

Keep:

* Same sidebar width
* Same spacing
* Same card sizes
* Same border radius
* Same typography
* Same purple primary color
* Same clean dashboard aesthetic

Do not introduce new design systems.

Do not change layout structure.

Only enhance the existing Challenge page with administrative CRUD functionality.
