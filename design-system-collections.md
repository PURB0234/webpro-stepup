# StepUp Collections Page Redesign

## Design Objective

Redesign the existing Collections page into a Challenge Collections feature.

Collections are curated groups of challenges designed to help users achieve specific goals.

Examples:

* Beginner Journey
* Weight Loss Program
* City Explorer Series
* Morning Walker Pack
* Weekend Warrior Collection

Keep the overall StepUp design language exactly the same.

Maintain:

* Sidebar layout
* Top navigation
* Card style
* White background
* Purple primary color
* Rounded corners
* Soft shadows
* Modern fitness dashboard aesthetic

---

# Visual Style Rules

IMPORTANT

Do not redesign the StepUp interface.

Keep the same:

* Sidebar width
* Typography
* Card appearance
* Border radius
* Shadows
* Purple accent color
* Spacing system

The page should feel like a natural extension of the existing StepUp platform.

The design should resemble a modern combination of Strava achievements and Spotify playlists, focused on walking challenge collections.
