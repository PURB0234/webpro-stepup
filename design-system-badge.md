# StepUp Badge Management System

## Design Objective

Create a Badge Management feature for StepUp.

Badges represent achievements earned by users after completing challenges, collections, milestones, or special events.

The design must follow the existing StepUp design system exactly.

Maintain:

* Existing sidebar
* Existing top navigation
* Purple primary color
* Rounded cards
* Soft shadows
* Clean dashboard aesthetic
* Consistent spacing and typography

Do not redesign the StepUp interface.

Only extend the platform with Badge functionality.

---

# Visual Style Rules

IMPORTANT:

Keep the interface visually identical to the current StepUp platform.

Do not modify:

* Sidebar structure
* Navigation layout
* Design language
* Color palette
* Card styling
* Typography

The final design should feel like a natural achievement and badge extension of the existing StepUp ecosystem.
